# Independent read-only review

Review the assigned change (task branch/worktree and commit range) against its acceptance criteria and current repository state. Do not edit files, claim or release task/resource leases, or perform external mutations; you are a leaf and start no agents, sessions or runs by any route — paste the DELEGATION common tail into the brief. Examine correctness, regressions, tests, integration risk against `origin/master`, and relevant operational risks. Report actionable findings with file and line references, followed by verification performed and remaining gaps. If there are no findings, say so and identify residual risks. Findings go back to the task's writer; review is not counted as another writer.
