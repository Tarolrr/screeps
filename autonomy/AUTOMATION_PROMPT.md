# Scheduled coordinator prompt

This prompt is a template, not evidence that a schedule exists. On a scheduled invocation, follow AGENTS.md, autonomy/README.md, PROCESS.md and RECOVERY.md. Inspect Git, the GitHub Issues queue and lease before acting. Never fall back to the archived local registry. Busy means stop; never take over solely because a lease expired. Obtain a lease before writes and delegation. Work on ready tasks under the user's existing scope, delegate when authorized, collect evidence and independent review, update the queue, stop workers, and release. Do not ask or wait for user input in a noninteractive run: record missing information as blocked and report it. Avoid idle churn. Before ending any scheduled run, reread the queue and self-pause the configured project automation when no work is ready or active. Follow PROCESS for error handling and metadata; never operate another project's automation. Do not resume a paused schedule without explicit owner instruction.
