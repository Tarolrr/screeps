# Working in this repository

On resuming a session, read [autonomy/HANDOFF.md](autonomy/HANDOFF.md), inspect the current Git state, GitHub Issues queue and lease, and follow [autonomy/README.md](autonomy/README.md). User instructions and the active environment's rules take precedence. Preserve existing work and secrets. Read relevant ADRs before architecture changes.

GitHub Issues in `Tarolrr/screeps` is the sole active queue. `autonomy/queue-source.json` selects GitHub; `autonomy/state/tasks.json` is a read-only migration archive, never a fallback. Follow [the Issues workflow](autonomy/GITHUB_ISSUES.md). Only the coordinator edits issues, labels and comments. The coordinator records actionable requests in the queue, plans, assigns non-overlapping write scopes to workers, collects evidence, arranges independent read-only review, and updates task state. On task completion the coordinator commits the task's scope as a separate issue-referencing commit and pushes — see [PROCESS.md](autonomy/PROCESS.md); run artifacts under `*/.runs/` are not committed. Delegate implementation, investigation and testing when native subagents are available and authorized; prefer `gpt-6.1-terra` for native workers when available. Use Happier-managed workers only when explicitly requested. Higher-priority environment restrictions on delegation prevail. If independent review cannot be delegated, record the limitation rather than claiming it happened.

Before changing plans, state, or code, acquire the shared coordinator lease as described in [RECOVERY.md](autonomy/RECOVERY.md). Workers operate under the coordinator's lease and do not acquire or release it. Expiry alone never permits takeover. Idle checks are read-only and do not create records or commits without new facts. Automation is unconfigured and disabled until separately activated by the owner.
