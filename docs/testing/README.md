# Документация модульного e2e

[План](PLAN.md) задаёт контракт и сценарии для dist и dist2; [матрица покрытия](COVERAGE.md) связывает их с модулями и доказательствами. Исходные исследования: [аудит dist](audit-dist.md), [аудит dist2](audit-dist2.md) и [исследование сервера](server-research.md). Это локальные документы рабочего дерева; их наличие не означает, что сценарии выполнены.

Для просмотра F0/ECO-01-D/HAR-01 мира через Steam-клиент есть отдельный
[долгоживущий spectator-инстанс](view.md): scratch server с реальной Steam
аутентификацией, slow/step режимами и безопасным teardown.

[Индекс опубликованных Issues](issues/README.md) связывает восемь задач с GitHub. GitHub Issues — единственная активная очередь; актуальные статусы и комментарии проверяются там. На момент передачи [E2E-SRV #6](https://github.com/Tarolrr/screeps/issues/6) выполняется двумя работниками с раздельными областями: создание изолированной среды и исследование пошагового барьера. Задачи #7–#13 ожидают зависимостей. Документы и изменения в рабочем дереве локальные и не закоммичены; проверяйте фактическое состояние Git и lease при возобновлении.

Изолированный сервер и согласованный потиковый снимок пока не объявлены проверенными. Существующий сервер пользователя и его мир должны сохраняться; admission и протокол безопасной отдельной установки описаны в плане.
