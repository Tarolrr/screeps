# Architecture decision records

Record durable, significant architectural decisions here, including context, alternatives, consequences and status. Do not create an ADR for every small change. Read relevant decisions before architectural work. Accepted decisions require user approval or fall within already authorized autonomous scope; ADRs do not grant additional permissions.
