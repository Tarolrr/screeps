# 0001. GitHub Issues — единственная активная очередь

- Дата: 2026-11-02
- Статус: accepted; частично заменён [ADR 0002](0002-task-leases-and-worktrees.md) (2026-11-08): общий lease и одна рабочая ветка заменены арендами задач, worktree на задачу и именованными ресурсами

## Контекст и решение

Пользователь напрямую уточнил, что очередь должна следовать принятой модели исходного проекта: GitHub Issues репозитория `Tarolrr/screeps` — единственная активная очередь, чат с координатором — основной интерфейс. После устранения ошибки 403 пользователем координатор перенёс пять задач, проверил статусы и зависимости обратным чтением и переключил `queue-source.json` на GitHub. `autonomy/state/tasks.json` — read-only архив переноса без fallback. См. [модель и команды](../../autonomy/GITHUB_ISSUES.md).

Координатор владеет очередью, назначает ограниченные scopes, принимает работу и организует независимое read-only ревью при разрешённом делегировании. Сохранялись общий lease и одна рабочая ветка (заменены в ADR 0002) и запрет takeover лишь по истечении lease. Открытые task issues имеют один статус, зависимости выполняются закрытием completed; ошибки доступа и данных не означают пустую очередь. Автоматизация остаётся отключённой до отдельной активации владельцем.

## Альтернативы и последствия

Локальный JSON менее доступен пользователю и сохранён только как архив переноса; скрытый fallback создавал бы конкурирующие источники истины. GitHub Projects, отдельный демон и новая локальная схема этим решением не выбираются. Зависимость от сети и `gh` означает fail-closed при ошибках. Решение не переносит чужие credentials, поставщиков или разрешения и не расширяет имеющийся пользовательский scope.
